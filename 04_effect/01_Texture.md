## 纹理采样与运用
GPU显存压缩重排后的逻辑二维矩阵，硬件采样（含mipmap，滤波，wrapmode）读取通道数据，对图像处理实现数据区域化定制

### 一、uv 与采样点

#### 1. 模型 uv - 遮罩与通道合并
* 将能有选择性对区域施加不同**强度**效果的单通道数值**灰度图**合并到同一贴图的四个通道以**节省采样**，对于需要对**不同通道**实现**差异化**采样的，仍需要**不同 uv** 对同一贴图采样后取出通道数据

#### 2. 自定义 uv
1. **重映射**
* 乘除：缩放采样范围，体现为纹理缩小与放大，结合采样器或**取余**重复采样
* 加减：偏移采样范围，体现为纹理沿轴相对偏移，结合时间等动态参数流动采样
###### 注：值域线性变换

2. **帧动画**
* 实现序列帧贴图动画效果，需按行列数求**帧大小**及其分量步长 `stepU = 1.0 / _ColCount, stepV = 1.0 / _RowCount` 并将 uv 重映射到帧范围内 `uv * float2(stepU, stepV)`；将时间对总帧数取余获取当前时间下的帧序号 `(int)fmod(_Time.y * _FrameSpeed, _frameCount)` ，随后将帧序号对列数分别取余数和商获取对应行列的**帧索引**
* 由于贴图帧一般按自左而右、自上而下的顺序，而 uv 以左下为原点，故在偏移索引之前需将 uv 移至左上角**首帧范围** `+ float2(0.0, (_RowCount - 1) * stepV)`，随后向左方 +u 与下方 -v **偏移取帧** `+ float2(stepU * idU, -stepV * idV)` 实现逐帧播放

###### 注：对于可能存在的浮点精度问题，建议计算索引有关数据使用相对 `int` 较快的 `uint` 存储

3. **极坐标**
* 模型 uv 重映射以贴图中心为原点 `x = u - 0.5, y = v - 0.5`，全弧度反正切函数求极角 `atan2(x, y) //[-PI, PI]` ，模长求极径 `length(x, y)` ，二者重映射为采样坐标 `theta/PI * 0.5 + 0.5` ，将 uv 由笛卡尔坐标系变换到极坐标系，实现将沿极角延伸的轴卷曲为环，以最小环坍缩为极点，沿极径延伸的轴拉伸为扇，以极点起射线为单元，表现为环形排列、外疏内密的圆化贴图
* 流动极角实现贴图角向旋转，流动极径实现贴图径向偏移，极坐标重映射实现扇与环个数缩放
###### 注：非线性映射

#### 3. LUT - lookUp Table
* 计算所得数据引入 uv 坐标，采样特定贴图数据，实现参数化映射，使常规效果风格化
###### 注：如 Ramp 图实现特定区域渐变

### 二、空间坐标

#### 1. 观察空间 - 屏幕 uv
* 观察空间坐标满足 +X 对屏幕向右，+Y 对屏幕向上，取 XY 分量作为 UV 将贴图**平铺于屏幕**进行采样，使纹理始终正对屏幕
###### 注1 透视畸变问题：对于透视相机，需手动透视除法将 UV 除以深度以**消除畸变**，随后 UV 不随物体与摄像机距离改变，平铺对屏幕固定；若使用裁剪空间
###### 注2 平铺透视问题：若需平铺随物体远近改变大小，选择原点到相机距离作为纹理**整体深度**乘入 UV ，使平铺随距离变化

#### 2. 模型空间 - 顶点动画
顶点着色器中，顶点经SRT与MVP变换后确定片元在屏幕位置，携带数据插值传入片元着色器，计算得片元色，显示在屏幕对应位置
* 顶点变换：1. **平移变换** `Translate` 坐标加位移量；2. **缩放变换** `Scale` 坐标乘缩放比；3. **旋转变换** `Rotate` 矩阵变换算式结果；变换顺序严格按 S - R - T , 旋转绕轴顺序严格按 Y - X - Z ，结合时间函数实现动画效果
###### 注：平移变换矩阵化需四维齐次矩阵，是非必要的；旋转变换算子：对于按序循环取自 xyzxy 的轮换对称三元坐标对 uvw，以 w 为旋转轴有 w=w，u=uc-vs, v=us+vc，其中 c=cos(rad), s=sin(rad)；旋转变换基准非原点需偏移
* 顶点色遮罩：顶点着色器不同于光栅化后 uv 能逐片元采样，故可取用的数据缺少贴图采样而回归**顶点数据**本身，其中可精确控制的顶点色可对局部**初步着色**，或类似贴图遮罩对区域**权重控制**
###### 注：1. 顶点密度：顶点着色器仅操作插值前的顶点数据，故最终效果平滑性、度受顶点密度限制；2. 阴影处理：顶点数据作为遮罩参与动画参数实现局部特定动画，需要同步处理动画后阴影

### 三、法线

#### 1. 观察空间 - MatCap
* **观察空间法线 RG 通道**对应**屏幕 XY**（左下角原点），[-1, 1] 重映射至 [0, 1] 作为 UV 采样单位圆面贴图（拓边），可证在法线单位化前提下 UV 采样点在单位圆内
* 采样面始终正对屏幕，预烘焙大量光照信息

#### 2. 世界空间
* 世界空间法线方向转化为模型表面不同方位，可实现顶侧底三区分离

#### 3. 模型空间 - 模型缩放
* 模型顶点沿法线偏移，实现对物体缩放后着色
* **双Pass背面膨胀法描边**：描边Pass顶点外扩后填充描边色并正面剔除形成边缘轮廓，物体Pass正常渲染，在法线不连续处会产生断裂且描边宽度随距离变化

### 四、透明贴图

#### 1. 半透明效果 - AlphaBlend
* 配置上，半透明渲染队列与渲染类型，关闭深度写入，设置混合模式
* 原理上，首先，不透明队列开启深度写入，对渲染对象由近及远测试深度，将最近片元深度与颜色写入缓冲，确保遮挡优化；而后，半透明队列关闭深入写入，对渲染对象由远及近测试深度，对比不透明深度图，将未被遮挡的片元与颜色缓冲混合后写入
* 效用上，对于不同物体，半透明队列物体由远及近的渲染顺序可确保物体逐层正确透明混合；对于同一物体，片元渲染顺序不必然满足由远及近的透明混合顺序，故可能存在前后错位问题，尤其是内部结构复杂的物体，若遮挡片元完全透明可能导致对应区域片元丢失
* 应对上，开启深度写入，使用预深度写入Pass，渲染半透明深度图，可解决物体级透明混合问题，像素级透明混合无法借此解决
###### 注：区别于 AlphaClip ，混合模式与片元丢弃思路不同；对于不透明队列可开启 `EarlyZ` 优化，提前丢弃被遮挡片元减少计算量，但有一定性能问题

#### 2. 预乘
* 将贴图不透明度提前乘入基本色，修改混合模式后，与原本使用透明通道效果类似
###### 注：混合模式源因子修改为 `One`，预乘在贴图制作层面完成了`SrcAlpha`操作 

### 五、噪声纹理

单通道二维随机数据，模拟自然界随机性

#### 1. 透明遮罩
* 灰度乘入片元不透明度半透明随机化，引入流动噪声采样实现**半透明随机流动**效果
* 插值控制强度，在纯白与噪声间插值调整振幅，一般需强化效果并负值截断，即 `max(0, lerp(1.0, 2.0 * var_Noise, _Int))`（如果说 pow 是非线性强化，那么上式就是线性强化）

#### 2. uv 扰动
* 率先采样，灰度重映射至对称区间作为基础色采样 uv 偏移值，实现图像随机扭曲，引入流动噪声采样对 uv 偏移速度叠加实现**图像动态随机扰动**
* 单噪声扰动随机性有限，将多噪声差速流动采样并分配不同扰动强度可实现随机性膨胀
* 同步参考原图像效果，对于需保持原样的区域，使用**扰动遮罩**乘入扰动强度控制；对于需限制形态的区域，使用**透明遮罩**乘入片元不透明度
###### 注：对屏幕纹理扭曲采样实现折射效果

### 六、时间动画

以持续自增的时间为输入信号，经函数处理波形，输出随时间变化的参数以实现动态效果

#### 1. 线性信号
* 关于时间的线性函数，调整时间系数可控制信号变化率，即动画速率
###### 注：流动采样采用时间线性映射采样重复内容，受存储容量与精度限制，需取余周期化处理

#### 2. 周期信号
信号参数：频率 `Frequency` / 周期 `Period` 控制动画速率；幅值 `Amplitude`、偏移 `Offset` 控制变化范围；相位 `Phase` 控制相对顺序
* 锯齿波：对时间取余得到线性循环
* 正弦波：取余时间作循环定义域优化，`2PI` 倍频率为时间系数界定周期以秒为单位
###### 注：`fmod(kt, n)=nfrac(kt/n) R=[0, n) T=n/k`

#### 3. 多元信号
* 对于顶点动画，将顶点参数引入信号参数增加时间函数维度，使变换结果由多个状态共同决定，波形作用于模型产生丰富变化
###### 注：uv 流动： `f(t, u, v)` ，实际为三元信号，采样点与贴图偏移；同一状态，如 `f(t, pos.y)` 在等高处同时等值
